# Cokform Preservation Archive

Cokform은 2026-10-10부터 신규 기능 개발을 중단하고 유지보수·보존 모드로 전환한다.

## 보존 원칙

- 원격 운영 데이터와 서비스 설정은 이 아카이브에 저장하지 않는다.
- 사용자 개인정보, Supabase 키, OAuth 비밀값, 백업 복호화 키를 저장하지 않는다.
- 이 디렉터리는 포트폴리오 참고용 브랜드·디자인 자료만 보존한다.
- 운영 코드와 데이터 복구는 별도의 원격 저장소 및 암호화 백업 절차를 사용한다.
- 신규 변경은 `main` 직접 수정이 아니라 별도 브랜치와 Pull Request로만 반영한다.

## 포함 자료

- `public-downloads/cokform-brand-guide.pdf` — 브랜드 가이드
- `public-downloads/cokform-design-guide.pdf` — 디자인 가이드
- `public-downloads/cokform-partnership-proposal.pdf` — 제휴 제안서
