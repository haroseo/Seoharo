## 1. 교차 비교 결론

Claude와 Codex의 방향은 대부분 일치한다. Cokform은 단순 설문 도구가 아니라 **한국 개인정보 실무에 맞는 신뢰 중심 폼 빌더**로 포지셔닝하고, 무료 MVP는 Cloudflare Pages에서 시작하며, 정식 데이터 계층은 Supabase 기반으로 분리 설계하는 것이 공통 결론이다.

차이는 역할에서 나온다. Claude는 제품 포지셔닝·차별화·디자인·운영 시나리오를 넓게 제안했고, Codex는 실제 코드·배포·보안 ID·데이터 모델·미완료 리스크를 구체화했다. 따라서 **제품 방향은 Claude와 Codex의 합의사항으로 볼 수 있고, 구현 완료 여부는 Codex 기록을 기준으로 하되 실제 저장소에서 재검증해야 한다.**

## 3. Claude가 보강한 내용

Claude 기록은 Cokform의 시장·제품 프레임을 보강한다. 핵심 포지셔닝은 “구글폼보다 한국 실무에 맞고, 네이버폼보다 브랜드 표현이 좋은 폼”이며, 기능 차별화 후보는 한국 업무 템플릿, 브랜드 폼, 중복·스팸·미완료 응답 관리, 개인정보 위험도 리포트다.

또한 Cokform을 단순 응답 수집기가 아니라 **응답 처리 업무함**으로 확장하는 방향이 제안됐다. 사용자는 응답을 모으는 데서 끝나지 않고 상태를 분류하고 후속 처리해야 하므로, 응답 상태·미완료·스팸 의심·담당자 처리 흐름이 장기 차별점이 될 수 있다.

디자인 측면에서는 기존 사용자 선호인 미니멀·플랫·고대비·Pretendard·글래스모피즘 배제를 기본값으로 보되, Cokform에는 Codex가 제안한 보라색 제품감과 초록 체크 신뢰감을 제한적으로 적용하는 것이 합리적이다. 이 조합은 공통 브랜드 규칙이 아니라 **Cokform 전용 디자인 결정**으로 관리한다.

## 4. Codex가 보강한 내용

Codex 기록은 이미 진행된 구현과 구체적인 보안 리스크를 보강한다.

첫째, 공개 폼 ID와 응답 ID를 시간 기반 값에서 안전한 랜덤 UUID 계열로 옮기기 위한 테스트·유틸리티·연결 작업이 진행됐다. Cloudflare Pages용 보안 헤더와 SPA 리다이렉트, 보안·개인정보 문서, Supabase 스키마 문서도 추가됐다.

둘째, 현재 구조의 가장 큰 위험은 폼 문서와 응답을 하나의 JSON 구조로 다루고 응답 제출 때 클라이언트가 전체 문서를 다시 저장하는 점이다. Supabase 연결 전 반드시 테이블 분리·RLS·권한 검증으로 바꿔야 한다.

셋째, 클라우드 실패 시 localStorage로 조용히 전환하는 동작은 운영상 위험하다. 사용자에게 성공으로 보이지만 운영자가 응답을 잃을 수 있으므로, 실패 표시·재시도·서버 큐·동기화 상태를 넣어야 한다.

넷째, localStorage 기반 1회 응답 제한은 보안 기능이 아니라 편의 기능에 가깝다. 서버 기준 중복 방지·rate limit·abuse 탐지로 교체해야 한다.

## 6. 통합 제품 정의

Cokform은 **한국형 개인정보 안심 UX를 기본값으로 제공하는 브랜드 폼 제작·응답 처리 도구**다. 제작자는 질문·동의·파일·브랜드 스타일을 설정하고, 응답자는 수집 목적과 보관 정보를 확인한 뒤 제출한다. 운영자는 응답을 상태별로 처리하고, 개인정보·파일 수집 위험도를 확인한다.

MVP에서 반드시 지켜야 할 선은 공개 폼 생성, 기본 질문 편집, 응답 저장, 랜덤 공개 코드, 기본 개인정보 안내, Cloudflare 배포다. 로그인·팀 권한·파일 업로드·결제·고급 분석·템플릿 마켓은 보안 기반이 먼저 갖춰진 뒤 단계적으로 붙인다.

## 7. 우선순위 보강안

### P0 — 출시 차단 요소

폼·질문·응답·동의 데이터를 분리하고 RLS를 적용한다. 클라이언트가 전체 문서를 덮어쓰지 못하게 API 경계를 만든다. 제출 실패를 성공처럼 보이지 않게 하며, 서버 기준 중복 방지와 기본 rate limit을 넣는다. 공개 링크와 응답 ID 생성 테스트를 실제 배포 빌드에서 다시 실행한다.

### P1 — 신뢰를 만드는 기능

개인정보 수집 목적·보관 기간·필수 여부·동의 버전을 질문 근처에 표시하고, 삭제 요청·보관 만료·감사 로그의 최소 구조를 마련한다. 응답 상태·스팸 의심·미완료 응답을 운영 화면에서 구분한다. 보안·개인정보 문서는 코드 동작과 일치시킨다.

### P2 — 차별화 기능

한국 업무 템플릿, 브랜드 폼, 개인정보 위험도 리포트, 응답 처리 업무함을 추가한다. 이 단계에서만 로고·색상·브랜드 커스터마이징과 팀 협업을 넓힌다.
