Claude 원본 사이트 · 주요 화면 12개

화면으로 보는 작업

공유된 Claude 사이트의 실제 화면을 가져왔습니다. Figma의 디자인 창고 시안과는 다른 버전입니다. 화면 속 아카이브 수와 자료 설명은 원본 표시이며 전체 정확성을 별도로 검증한 것은 아닙니다. 준비 중 메뉴와 미정리 상세도 그대로 구분했습니다. 구성 이유는 화면을 바탕으로 한 해석입니다.

홈페이지

화면 해설

검색창, 국내·해외 기업과 대학의 분류, 대표 레퍼런스와 전체 목록 진입을 보여주는 첫 화면입니다.

구성 이유 · 해석

목적이 정해진 사용자는 검색으로, 아직 찾는 자료가 없는 사용자는 분류와 대표 자료로 시작할 수 있게 두 경로를 나눴습니다.

02 / WEB

디자인 가이드 전체 목록

화면 해설

지역·기관 필터, 결과 내 재검색, 자료 카드와 페이지 이동을 담은 목록입니다. 원본의 첫 페이지를 보여줍니다.

구성 이유 · 해석

필터와 자료를 좌우로 나눠 탐색 조건을 유지하면서 결과를 비교할 수 있는 구성입니다.

화면 목록으로 ↑

03 / WEB

국내 기업 디자인 가이드

화면 해설

홈에서 국내 기업을 선택했을 때의 목록입니다. 지역과 기관 유형의 선택 상태가 표시됩니다.

구성 이유 · 해석

전체 목록과 같은 레이아웃 안에서 선택 상태만 달라져, 분류를 바꿔도 탐색 방식이 이어집니다.

화면 목록으로 ↑

04 / WEB

해외 대학 디자인 가이드

화면 해설

해외 대학의 레퍼런스를 모은 필터 결과이며 자료 목록과 페이지 이동을 확인할 수 있습니다.

구성 이유 · 해석

기업과 대학을 같은 정보 구조로 다루되 분류를 분명히 보여줘 서로 다른 자료를 비교할 수 있도록 구성했습니다.

화면 목록으로 ↑

05 / WEB

검색 결과 · 블루

화면 해설

원본에서 블루를 검색했을 때 결과 수, 재검색 입력, 분류 필터와 토스 자료가 표시된 화면입니다.

구성 이유 · 해석

어떤 검색으로 나온 결과인지 제목에 남기고, 결과 안에서도 범위를 좁힐 수 있게 구성했습니다.

화면 목록으로 ↑

06 / WEB

검색 결과 없음

화면 해설

일치하는 자료가 없을 때 검색어 확인 안내, 필터 초기화와 홈으로 돌아가기 링크를 보여줍니다.

구성 이유 · 해석

빈 결과로 흐름이 끝나지 않게 다시 탐색할 수 있는 선택지를 제공합니다.

화면 목록으로 ↑

구성 이유 · 해석

자료를 읽는 화면과 공식 원문으로 이동하는 행동을 구분해, 아카이브와 자료 제공 기관의 역할을 나눴습니다.

작업에 담은 생각.

01

무엇을 만들었나요?

디자인을 참고할 때 기업과 대학의 공식 자료를 한곳에서 찾을 수 있도록 구성한 웹 프로토타입입니다. 자료 소개에서 원문 가이드로 바로 이동하는 흐름을 담았습니다.

02

화면에서 확인할 수 있는 것

검색, 국내·해외와 기업·대학 분류, 가이드 목록과 상세 화면을 구성했습니다. 공식 자료를 만든 기관과 아카이브의 역할을 구분합니다.

03

현재 작업 범위

공유된 Claude 아티팩트 버전입니다. 컬러 팔레트와 타이포그래피 메뉴는 준비 중이며, 아카이브 전체 자료의 정확성이나 서비스 운영 성과를 검증한 결과는 아닙니다.

개인 프로젝트 기록입니다. 공개 링크의 현재 서비스 상태는 달라질 수 있습니다.
