# MOFA Bot

MOFA | 대한민국 외무부 Discord 서버 전용 업무 봇의 초기 설계다. 이 봇은 **기존 역할과 채널을 생성·수정하지 않는다.** 서버에 이미 존재하는 역할을 이름 또는 ID로 조회하고, 허용 목록에 있는 역할만 부여한다.

## 카테고리별 동작

| 영역 | 동작 |
|---|---|
| MoFA | 정보 채널 임베드 게시, 가이드 포럼 스레드 작성, 인증 승인 결과 반영 |
| Verify | 한국어/영어 양식 판별, 형식 검증, 관리자 포털 로그, 승인, 닉네임 변경, 역할 부여, 원문 삭제 |
| Notice | 공지사항은 사람 작성. 브리핑은 Markdown 입력을 임베드로 변환. 일정은 정돈된 일정 명령어로 관리. |
| 채용정보 | 관리자 포털에서 공고 작성, 포럼 태그 적용, 공개 채널 게시 |
| 국가 포럼 | 국가별 외교관계 문서를 임베드로 생성·수정·삭제 |
| 업무포털 | 가이드·문서·일정·채용·승인·감사로그를 명령어로 처리 |
| 대외비 | 비공개 스레드 또는 외부 암호화 저장소에 보관. 파쇄는 서로 다른 승인자 3명 이상 필요 |
| 로그 | 인증, 역할, 닉네임, 게시, 수정, 삭제, 문서 열람, 파쇄, 권한 오류를 별도 로그 채널에 기록 |

## 중요 제약

기존 역할 `0`, `1`, `2`, `Citizens`, `Overseas Citizens`를 포함해 서버의 역할은 코드가 생성하거나 이름을 바꾸지 않는다. 환경변수로 역할 ID를 지정하면 ID를 우선 사용하고, 이름 조회는 초기 점검용으로만 사용한다. 역할 계층상 봇보다 높은 역할은 절대 부여하지 않으며, 권한이 불명확하면 실패하고 관리자 로그만 남긴다.

대외비 원문은 Discord 메시지나 첨부파일에 저장하지 않는 것을 기본값으로 한다. 문서 파일은 별도 암호화 저장소에 저장하고, Discord에는 문서번호·등급·버전·만료 링크만 남긴다. 파쇄는 즉시 삭제 버튼이 아니라 3인 승인 수집, 재확인, 암호키 폐기, 저장소 삭제, 백업 삭제 예약, 감사로그 보존 순서로 처리한다. 법적·운영상 보존 의무가 있는 백업은 물리적으로 임의 삭제하지 않고 보존정책에 따라 폐기한다.

## 환경변수

`../.env.example`을 복사해 봇 토큰과 채널·역할 ID를 입력한다. 토큰은 Git에 커밋하지 않는다.

## 실행

```bash
npm install
npm run dev
```

현재 코드는 실제 서버에 접속하지 않는 안전한 초기 골격으로 시작한다. 토큰이 없으면 실행을 거부하고, 명령어 등록이나 메시지 삭제 같은 변경 작업은 별도 구현 단계에서 승인 후 추가한다.
